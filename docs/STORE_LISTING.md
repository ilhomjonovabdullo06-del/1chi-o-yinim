# Do'kon matnlari (Play Console -> Store listing)

## Ilova nomi (30 belgigacha) - variantlar (noyob bo'lganini tanlang)
- Boks: Joystik Jangi
- Boks Jang: 2 Joystik

## Qisqa tavsif (80 belgigacha)
**UZ:** Joystiklar bilan boks: 3 raund, kompyuterga qarshi yoki 2 telefonda PvP!
**EN:** Joystick boxing: 3 rounds vs AI or 2-phone PvP on the same Wi-Fi!

## To'liq tavsif (UZ)
Boks - joystiklar bilan boshqariladigan tezkor boks o'yini. Har qo'l alohida joystikka bog'langan: joystikni oldinga tez surib kuchli zarba bering, orqa tomonga surib himoyalaning.

Imkoniyatlar:
- 3 raund, har biri 1:30 daqiqa, qo'ng'iroq ovozi va nokaut
- Kompyuterga qarshi 3 daraja: Oson, O'rta, Qiyin
- 2 telefonda PvP: bir xil Wi-Fi yoki hotspot orqali, internetsiz va serversiz
- 3 joystikli yoki 2 joystikli boshqaruv, joylashuvni tanlash mumkin
- Qo'shimcha qiyinlik: "Himoya charchog'i" - himoyani 3 soniyadan uzoq ushlasangiz, doira kichrayadi
- Reklamasiz, ro'yxatdan o'tishsiz, shaxsiy ma'lumot yig'maydi

## Full description (EN)
Boks is a fast joystick boxing game. Each glove has its own joystick: flick forward for a strong punch, pull back to guard. 3 rounds of 1:30, bell, knockouts, three AI levels (Easy, Medium, Hard), 2-phone PvP over the same Wi-Fi or hotspot (no internet or server needed), 3-stick or 2-stick controls, and an optional "Guard fatigue" rule. No ads, no accounts, no data collection.

## Kategoriya / teglar
Kategoriya: O'yinlar -> Sport (yoki Arcade). Teglar: boxing, fighting, multiplayer, local multiplayer.
